# Padrões de Projeto GOF

Os Padrões de Projeto GOF (Gang of Four) são um conjunto de 23 padrões que foram introduzidos no livro "Design Patterns: Elements of Reusable Object-Oriented Software" escrito por Erich Gamma, Richard Helm, Ralph Johnson e John Vlissides, conhecidos como Gang of Four. Esses padrões são divididos em três categorias principais: Criacionais, Estruturais e Comportamentais.

## 1. Padrões Criacionais
Esses padrões focam no processo de criação de objetos, buscando tornar esse processo mais flexível e reutilizável. Eles incluem:

- Singleton Pattern
- Factory Method Pattern
- Abstract Factory Pattern
- Builder Pattern
- Prototype Pattern

**Leia mais sobre os Padrões Criacionais [aqui](./creational/README.md).**

## 2. Padrões Estruturais
Os padrões estruturais são projetados para facilitar a composição de classes e objetos para formar estruturas mais complexas. Eles incluem:

- Adapter Pattern
- Bridge Pattern
- Composite Pattern
- Decorator Pattern
- Facade Pattern

**Leia mais sobre os Padrões Estruturais [aqui](./structural/READM.md).**

## 3. Padrões Comportamentais
Os padrões comportamentais se concentram nas responsabilidades e interações entre objetos. Eles incluem:

- Chain of Responsibility Pattern
- Command Pattern
- Interpreter Pattern
- Iterator Pattern
- Mediator Pattern
- Observer Pattern
- Template Method Pattern
- Strategy Pattern

**Leia mais sobre os Padrões Comportamentais [aqui](./behavioral/README.md).**
